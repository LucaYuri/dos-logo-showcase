# DOS — Logo Showcase

Statische Seite mit 46 Logo-Entwürfen für den Verein **«DOS» (Deko und So)**.

- `index.html` — die ganze Seite (HTML, CSS, JS in einer Datei)
- `logos/` — die Entwürfe als SVG (`Frame 2.svg` … `Frame 47.svg` = Entwurf 01 … 46)
- `layout webiste.svg` — das Layout-Mockup
- `a_LucaYuri_Logo.PNG` — Logo im Kopfbereich

**Funktionen:** alle Entwürfe der Reihe nach, Favorisieren per Stern (gespeichert im `localStorage`),
Filter «Alle / Favoriten», «Nach oben»-Button, responsives Layout für Mobile.

Lokal ansehen:

```sh
python3 -m http.server
# → http://localhost:8000
```
